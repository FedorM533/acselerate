# Фокус-пруд Щит: приложение для Android

Работает вместе с «Фокус-прудом» на ПК, но и без него: блокировка идёт на самом телефоне.
Протокол связи: `../docs/PHONE_PROTOCOL.md`. Только Android (iPhone запрещает такие приложения).

## Что умеет
- **Чёрный список** (нельзя выбранное) и **белый список** (можно только выбранное).
  Белый список без единого приложения ничего не блокирует.
- **Мягко**: экран «Идёт учёба» с кнопкой «всё равно открыть на 5 минут».
  **Жёстко**: только «вернуться», учёбу нельзя прервать до конца таймера.
- Учёба стартует с компьютера (связь по Wi-Fi, сопряжение по QR) или на самом телефоне.
  Если связь с ПК оборвалась, учёба с ПК доходит до своего конца сама.
- Всегда разрешены: главный экран, звонилка, СМС по умолчанию, клавиатура, настройки, система.
- Приватность: служба доступности слушает только смену окна. Содержимое экрана, тексты и пароли не
  читаются. На ПК уходят только вид события и название пакета.

## Установка на телефон
1. Файл `FocusShield-debug.apk` скопируйте на телефон (кабелем, через «Файлы» или Telegram) и откройте.
   Разрешите установку из этого источника. Либо `adb install -r FocusShield-debug.apk`.
2. Откройте «Фокус-пруд Щит» → «Включить службу блокировки» → найдите приложение и включите.
   **Если пункт серый** (Android 13+ для приложений не из магазина): Настройки → Приложения →
   Фокус-пруд Щит → ⋮ вверху справа → «Разрешить ограниченные настройки». Затем снова включите службу.
3. Разрешите уведомления (нужны для постоянной связи с ПК).
4. На ПК: «Настройки» → «Телефон по Wi-Fi» → включить, «Сохранить», «Подключить телефон».
   На телефоне: «Сканировать QR с компьютера». Телефон и ПК должны быть в одной сети Wi-Fi.
   Не получается сканировать: откройте QR камерой или вставьте ссылку `focusfarm://pair?...` вручную.
5. Выберите режим списков и приложения.

На Samsung отключите оптимизацию батареи для приложения (Настройки → Приложения → Фокус-пруд Щит →
Батарея → «Без ограничений»), иначе система может усыплять связь с ПК.

## Сборка
Нужны JDK 17+ и Android SDK (`ANDROID_HOME`), платформа 36. Android Studio не обязательна.

```
cd android
gradlew testDebugUnitTest assembleDebug     # APK: app/build/outputs/apk/debug/app-debug.apk
```

Android Gradle Plugin не принимает пути с кириллицей. Если проект лежит в такой папке, скопируйте
его в ASCII-путь (например `C:\fs-build`) и соберите там: `build_debug.ps1` делает это сам.

## Устройство
| Файл | Что делает |
|---|---|
| `FocusAccessibilityService` | видит смену окна, решает по `Policy`, показывает `BlockActivity` |
| `Policy`, `ShieldState` | чистая логика списков и состояния (покрыта тестами в `app/src/test`) |
| `LinkService` | WebSocket к ПК: состояние, heartbeat, отчёты; переподключение 2→60 с |
| `PairingLink`, `PairingClient` | разбор QR и обмен секрета на токен; принимает только адреса домашней сети |
| `Events` | очередь событий для ПК, переживает отсутствие связи |
| `MainActivity`, `AppPickerActivity` | экраны |

## Ограничения
- Проверено сборкой и юнит-тестами; на настоящем телефоне нужна ручная проверка (см. `../docs/PROGRESS.md`).
- Трафик с ПК не шифруется (`ws://` в домашней сети).
- Отключить службу блокировки в настройках телефона можно: приложение лишь громко предупредит и сообщит ПК. От владельца телефона это не защитит.
