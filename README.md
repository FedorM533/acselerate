# Фокус-ферма

Программная часть проекта **«Фокус-док»**: подставка для телефона + программа на
ноутбуке. Положил телефон в подставку — началась учебная сессия. Пока ты
работаешь, на огороде растут растения; отвлёкся — рост на паузе и появляются
сорняки. Урожай приносит монеты, за монеты открываются новые растения и грядки.

Всё работает локально (`127.0.0.1`), без интернета, аккаунтов и облака.

## Установка и запуск

Нужен **Python 3.11+** (Windows — основная ОС; Linux/macOS — по возможности).

```bat
run.bat
```

При первом запуске скрипт создаст виртуальное окружение `.venv`, установит
зависимости из `requirements.txt` и откроет браузер на http://127.0.0.1:8765/.
Linux / macOS: `./run.sh`.

Вручную:

```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m focusfarm
```

### Флаги

| Флаг | Что делает |
|---|---|
| `--demo [N]` | демо-режим: время ускорено в N раз (по умолчанию 30), плашка «ДЕМО ×N», панель разработчика |
| `--dev` | панель разработчика (виртуальный телефон, принудительная категория окна) без ускорения |
| `--port N` | другой порт (по умолчанию 8765) |
| `--db PATH` | другой файл базы |
| `--fresh` | начать с чистой фермы (только вместе с `--db`, основную базу не трогает) |
| `--no-browser` | не открывать браузер |

Демо для защиты: **`run_demo.bat`** и сценарий [`docs/DEMO.md`](docs/DEMO.md).
Ускорение можно включить и переменной окружения `FOCUSFARM_DEMO_SPEED=30`.

## Как это работает

1. **Монитор активности** раз в секунду узнаёт имя программы активного окна и
   сколько секунд не было ввода с клавиатуры/мыши. Заголовок окна используется
   только в памяти, чтобы понять категорию (`config/rules.yaml`): работа,
   нейтрально, отвлечение.
2. **Машина состояний** (`focusfarm/session/state_machine.py`) по прозрачным
   правилам и порогам из `config/settings.yaml` решает: «Работаешь», «Пишешь в
   тетради», «Кажется, отвлёкся», «Отвлёкся», «Телефон вынут», «Пауза».
3. **Игра** (`focusfarm/game/engine.py`): растения растут только в фокусе,
   сорняк — за каждую минуту непрерывного отвлечения (максимум 3), качество
   урожая — по числу отвлечений, серия дней с ≥ 25 минутами фокуса, дождь при
   серии 3+ дня (+10 % к росту). Растения никогда не погибают.
4. **Подставка** (ESP32) показывает состояние светом и звуком. Без подставки
   работает виртуальная — цветной круг на вкладке «Сессия».

## Подставка ESP32

- Прошивка: [`firmware/focus_dock/focus_dock.ino`](firmware/focus_dock/focus_dock.ino)
  (пины — константами вверху файла; библиотеки «Adafruit NeoPixel» и
  «DFRobotDFPlayerMini»). Плата в Arduino IDE: «ESP32 Dev Module».
- Протокол: [`firmware/PROTOCOL.md`](firmware/PROTOCOL.md).
- Подключение: вкладка «Настройки» → «Подставка (COM-порт)» → «Сохранить».
  Если связь пропала, программа не падает: пишет «Подставка не подключена»,
  переключается на виртуальную и переподключается каждые 3 секунды.
- Проверка протокола вручную:
  ```bat
  .venv\Scripts\python -m focusfarm.tools.serial_console --list
  .venv\Scripts\python -m focusfarm.tools.serial_console --port COM3
  ```

## Полезные команды

```bat
.venv\Scripts\python -m pytest -q                 :: все тесты
.venv\Scripts\python -m focusfarm.activity        :: что видит монитор активности (Ctrl+C — выход)
.venv\Scripts\python -m focusfarm.tools.make_sprites  :: перерисовать SVG-спрайты
```

## Приватность

- Не используем камеру, микрофон, скриншоты. Не записываем, какие клавиши
  нажаты, — только время с последнего ввода (`GetLastInputInfo`).
- Заголовки окон **не сохраняются**: в базу `data/focusfarm.db` пишем только
  состояние, категорию и имя программы (это проверяет тест).
- Сервер слушает только `127.0.0.1` — с других компьютеров его не видно.

## Структура

```
config/          settings.yaml (пороги, игра), rules.yaml (правила окон)
focusfarm/
  clock.py       Clock / RealClock / FakeClock
  config.py      загрузка и проверка конфигов
  events.py      шина событий
  activity/      монитор активности (Windows, macOS, запасной) и классификатор
  session/       машина состояний, менеджер сессии, статистика
  game/          растения и игровая логика
  sensors/, device/  датчик телефона, свет/звук, связь с ESP32
  reactions.py   состояние → свет и звук (с ограничением частоты)
  storage/db.py  SQLite и миграции
  api/server.py  REST + WebSocket
  web/           интерфейс: index.html, app.js, style.css, sprites/
firmware/        прошивка ESP32 и протокол
docs/DEMO.md     сценарий демо
tests/           pytest
```

## Известные ограничения

- В демо-режиме ускоряются пороги и рост, но **не** время простоя клавиатуры:
  иначе «кажется, отвлёкся» включалось бы через 6 секунд без движения мыши.
- На macOS нет заголовков окон — классификация только по названию приложения
  (нужен `pyobjc`, иначе «монитор активности недоступен»). На Linux работает
  только датчик телефона.
- Если окно браузера одно на учёбу и развлечения, различаем их по заголовку
  вкладки — правила стоит подстроить под себя во вкладке «Настройки».
