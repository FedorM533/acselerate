# Фокус-ферма

Программная часть проекта «Фокус-док». Положи телефон в подставку — начнётся
учебная сессия. Пока ты работаешь, на огороде растут растения.

## Установка и запуск (Windows)

Нужен Python 3.11 или новее.

```bat
run.bat
```

Скрипт сам создаст виртуальное окружение, установит зависимости и откроет
браузер на http://127.0.0.1:8765/.

Linux / macOS: `./run.sh`.

## Тесты

```bat
.venv\Scripts\python -m pytest -q
```
