# Сценарий демо на защите (2–3 минуты)

Демо-режим ускоряет время в **30 раз**: 1 настоящая секунда = 30 секунд «игры».
Редис (10 минут фокуса) вырастает за 20 секунд. В углу экрана горит плашка
**«ДЕМО ×30»** — жюри видит, что время ускорено.

Интернет **не нужен**: сервер работает на `127.0.0.1`, вся графика и скрипты
лежат локально. «YouTube» показываем через панель разработчика, а не через сайт.

## Подготовка (до выхода на сцену)

1. Запусти `run_demo.bat` (Linux/macOS — `./run_demo.sh`).
   Он стартует с **чистой фермой** в `data/demo.db` — основная ферма не трогается.
2. Браузер откроется сам: http://127.0.0.1:8765/. Разверни его на весь экран
   (F11), масштаб 100–125 % под проектор.
3. Нажми 🔈 в правом верхнем углу → 🔊: звуки будут играть из колонок ноутбука
   (если настоящей подставки нет).
4. Справа внизу — **панель разработчика**: переключатель «Телефон в подставке»
   и выбор «Окно». Поставь «Окно: работа».
5. Подставка ESP32 подключена? Выбери её COM-порт в «Настройках» и проверь,
   что на вкладке «Сессия» написано «Подставка подключена». Если нет — ничего
   страшного: работает виртуальная подставка (цветной круг на вкладке «Сессия»).

## Сценарий

| Время | Что делаем | Что видит жюри | Что говорим |
|---|---|---|---|
| 0:00 | Вкладка «Ферма». Кладём телефон в подставку (или включаем «Телефон в подставке») | Сессия стартует сама, круг/кольцо **зелёное**, звук «сессия началась», на грядке семечко редиса | «Положил телефон — начал учиться. Никаких кнопок.» |
| 0:15 | Ждём ~12 секунд, «Окно: работа» | Редис растёт: семя → росток → молодое растение. Таймер на вкладке «Сессия» бежит в 30 раз быстрее | «Пока я работаю в VS Code, огород растёт. Мы смотрим только, какая программа активна, — без камеры и без записи клавиш.» |
| 0:40 | «Окно: отвлечение (YouTube)» | Статус «Кажется, отвлёкся» (**жёлтый**), через секунду «Отвлёкся» (**красный**), звук, уведомление. Рост остановился, через 2 секунды на грядке **сорняк** | «Отвлёкся — рост на паузе, появляется сорняк. Растения никогда не погибают: только мягкие последствия.» |
| 1:00 | «Окно: работа» | Через пару секунд снова **зелёный**. Кликаем по сорняку — он пропадает | «Вернулся к работе — всё снова растёт. Полоть можно, только если уже поработал 5 минут в этой сессии.» |
| 1:15 | *(по желанию)* Берём телефон из подставки, через пару секунд возвращаем | «Телефон вынут», кольцо **мигает красным**, мягкий звук; после возврата — зелёный | «30 секунд на то, чтобы ответить маме, — бесплатно. Дольше — растения ждут.» |
| 1:30 | Ждём ~8 секунд | Редис созрел: анимация, звук «урожай», кнопка «Собрать +N» | |
| 1:40 | Кликаем по грядке | Монеты в шапке, звёзды качества (★★ — было одно отвлечение) | «Качество урожая зависит от того, сколько раз отвлекался. Монеты — на новые растения и грядки.» |
| 1:50 | Вкладка «Магазин» | Морковь, тыква, расширение огорода, декор | |
| 2:00 | Вкладка «Сессия» → «Завершить», затем «Статистика» | Минуты в фокусе, 2 отвлечения (окно / телефон), **полоса-хронология** сессии, раскрашенная по состояниям | «Видно не „сидел 3 часа“, а сколько было честной работы и что отвлекало.» |

Этот сценарий автоматически проверяется тестом `tests/test_demo.py`.

## Если что-то пошло не так

- **«Кажется, отвлёкся» без причины.** Скорее всего, в панели разработчика
  выбрано «Окно: настоящее», а активное окно — сам браузер (он «нейтральный»).
  Выбери «Окно: работа».
- **Сессия не стартует, когда кладёшь телефон.** Сессия уже идёт или только
  что закончилась — нажми «Начать» на вкладке «Сессия».
- **Нет звука.** Включи 🔊 в шапке (браузеры не играют звук без клика).
- **Подставка отвалилась.** Программа сама переключится на виртуальную
  подставку и будет переподключаться каждые 3 секунды — демо продолжается.
- **Начать заново.** Закрой окно консоли и снова запусти `run_demo.bat` —
  ферма будет чистой.

## Другие варианты запуска

```bat
run.bat --demo 10                        :: помедленнее: жёлтый держится 3 с, редис — за минуту
set FOCUSFARM_DEMO_SPEED=30 && run.bat   :: ускорение через переменную окружения
run.bat --dev                            :: панель разработчика без ускорения
```
