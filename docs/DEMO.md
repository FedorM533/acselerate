# Показ «Фокус-пруда» на защите (2–3 минуты)

Демо-режим ускоряет время в **30 раз**: 1 настоящая секунда = 30 секунд «игры».
Морковь (25 минут фокуса) вырастает меньше чем за минуту. Плашка **«ДЕМО ×30»**
в шапке показывает жюри, что время ускорено. Всё работает без интернета.

Есть два способа показа:
- **вручную** — ниже, с настоящим YouTube (нужен интернет только для самого YouTube);
- **автопилот** — `python scripts/demo_autopilot.py`, сценарий играет сам,
  а с `--step` идёт по Enter (см. конец файла).

## Подготовка (до выхода на сцену)

1. Запусти `run_demo.bat` (Linux/macOS — `./run_demo.sh`). Демо живёт в
   `data/demo.db`, основной пруд не трогается.
2. Браузер откроется сам: http://127.0.0.1:8765/. Разверни на весь экран (F11).
3. Нажми 🔈 в шапке → 🔊, чтобы звуки играли из колонок.
4. Открой заранее вкладку браузера с YouTube (любое видео) и окно VS Code.
5. Подставка: «Настройки» → «Подставка» → выбери COM-порт → «Сохранить».
   В шапке должно быть «🔌 подключена». Без подставки — «виртуальная», это нормально.

## Сценарий

| Время | Делаем | Видит жюри | Говорим |
|---|---|---|---|
| 0:00 | Вкладка «Пруд». Включаем телефон кнопкой в панели разработчика (в жизни — кабель) | Сессия стартует сама, кольцо подставки **зелёное**, «Работаешь 🐟», в пруду икринка | «Положил телефон — начал учиться. Никаких кнопок.» |
| 0:15 | Переключаемся в VS Code, печатаем пару строк, возвращаемся в браузер | Рыбка растёт, под ней полоска прогресса, вода чистая | «Программа видит только, какая программа активна. Без камеры, без записи клавиш, заголовки окон не сохраняются.» |
| 0:40 | Переключаемся на вкладку **YouTube** на 3–4 секунды, потом обратно на пруд | «Кажется, отвлёкся…» (**жёлтый**, вода слегка мутнеет) → «Отвлёкся — вода мутнеет» (**коралловый**, вода мутная), звук, через пару секунд — **ил** | «Отвлёкся — рост на паузе и ил. Рыбки никогда не погибают — только мягкие последствия.» |
| 1:00 | Снова VS Code, затем пруд. Клик по илу | Вода снова чистая. Ил пропал | «Вернулся к работе — всё растёт. Чистить воду можно, когда уже поработал 5 минут.» |
| 1:15 | Берём телефон, через 1 секунду возвращаем | Ничего страшного — льготные 30 секунд | «Ответить маме можно. Дольше 30 секунд — кольцо мигает красным.» |
| 1:30 | Ждём | Морковь созревает: подпрыгивает, блестит, «Собрать +15» | |
| 1:45 | Клик по выросшей рыбке | **Монеты летят** к счётчику, всплывает «+15 ★★» | «Качество — по числу отвлечений. Монеты — на новых рыбок и места в пруду.» |
| 1:55 | «Магазин» | Закрытые растения с замочком и ценой | |
| 2:05 | «Сессия» → «Завершить», затем «Статистика» | Минуты фокуса, отвлечения (окно / телефон), **цветная хронология** сессии | «Видно не „сидел 3 часа“, а сколько было честной работы и что отвлекало.» |

> При ×30 «жёлтый» держится около секунды. Хочется, чтобы жюри его рассмотрело, —
> запусти `run.bat --demo 10 --db data\demo.db --fresh`: жёлтый 3 секунды,
> золотая рыбка за ~2,5 минуты.

## План «Б»

| Что случилось | Что делать |
|---|---|
| **Подставка не подключилась** (в шапке «не подключена» или «виртуальная») | Ничего не перезапускать. Справа внизу **панель разработчика**: галочка «Телефон в подставке» = положить/взять телефон. Или клик по нарисованной подставке на вкладке «Сессия». Свет и звук — на виртуальной подставке и из колонок ноутбука (включи 🔊). |
| **Нет интернета, YouTube не открывается** | Панель разработчика → «Окно: отвлечение (YouTube)», вернуть — «Окно: работа». |
| **«Кажется, отвлёкся» без причины** | Активное окно — сам браузер (он «нейтральный»). Панель разработчика → «Окно: работа». |
| **Сессия не стартует** | Вкладка «Сессия» → «▶ Начать». |
| **Всё пошло не так** | Закрой консоль и снова запусти `run_demo.bat` — пруд чистый. Или запусти автопилот. |

## Автопилот

```bat
.venv\Scripts\python scripts\demo_autopilot.py          :: всё само, ~2 минуты, браузер откроется
.venv\Scripts\python scripts\demo_autopilot.py --step   :: шаги по Enter — ведёшь показ сам
.venv\Scripts\python scripts\demo_autopilot.py --pause 2 --speed 30
```

Автопилот запускает свой сервер на http://127.0.0.1:8766/ с чистой `data/demo.db`
(120 стартовых монет, открыта золотая рыбка) и печатает, что происходит:
телефон → золотая рыбка → работа → тетрадь 15 с → YouTube (жёлтый, красный, ил) →
возврат и очистка воды → кабель отключён на 10 игровых секунд → выпуск рыбки → статистика.
В конце открой вкладку «Статистика».

Скриншоты всех шагов в двух разрешениях: `python scripts/screenshots.py`
(нужен `pip install -r requirements-dev.txt`) → `docs/screenshots/`.
