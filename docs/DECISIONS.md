# Принятые решения по неоднозначным местам ТЗ

ТЗ просит спрашивать при неоднозначности, но работа шла без остановок, поэтому
здесь записано, как каждое место истолковано. Всё легко поменять — скажите.

| Место в ТЗ | Решение | Где в коде |
|---|---|---|
| 9.4: демо ускоряет «таймеры порогов» | Ускоряются все пороги и рост, но не время простоя клавиатуры (иначе «кажется, отвлёкся» через 6 с без мыши) | `session/manager.py` |
| Демо: сессия 25 мин при ×30 = 50 с — мало для сценария | В демо своя длина сессии `session.demo_length_min: 120` (4 минуты) | `config/settings.yaml` |
| Нет подставки и режим `normal` — телефон «положить» нельзя | Виртуальный телефон в `normal` считается лежащим; в `dev`/`demo` его кладут вручную | `api/server.py` → `build_manager` |
| 9.2: «сорняк на грядке соседнего растения — урожай −20 %» | −20 % один раз, если сорняк на этой грядке или на соседней (сверху/снизу/слева/справа) | `game/engine.py` → `harvest_value` |
| Сорняки: сколько на одной грядке | Не больше одного на грядку, всего не больше 3; после сбора урожая сорняк остаётся | `game/engine.py` |
| «Непрерывное отвлечение» для сорняков | `DISTRACTED` и `PHONE_OUT` подряд считаются одним отвлечением; `MAYBE`/пауза сбрасывают счёт | `game/engine.py` → `tick` |
| Эпизоды для качества урожая | Эпизод — вход в `DISTRACTED`/`PHONE_OUT` из другого состояния; переход `DISTRACTED → PHONE_OUT` — тот же эпизод | `game/engine.py` |
| Растение созрело посреди сессии | Растёт дальше не нужно; после «Собрать» на активной грядке сразу сажается то же растение | `game/engine.py` → `harvest` |
| Грядка по умолчанию при старте | Сначала недоросшее растение (продолжаем), иначе первая пустая | `game/engine.py` → `default_plot` |
| Серия дней, если сегодня норма ещё не набрана | Серия не обрывается — считаем до вчера | `game/engine.py` → `streak` |
| Звук `SOUND 2` «повтор не чаще раза в 3 минуты» | Звук при входе в `DISTRACTED`, но не чаще раза в 3 мин; плюс любые два звука не чаще раза в 5 с | `reactions.py` |
| Гистерезис: «хорошие» сигналы | `FOCUS` и `NOTEBOOK`; из `PAUSED` возвращаемся сразу | `session/state_machine.py` |
| Пауза и таймеры | На паузе таймеры машины состояний сбрасываются, время паузы не съедает длину сессии | `state_machine.py`, `manager.py` |
| «Ты ещё здесь?» | Ответ ждём `thresholds.notebook_answer_s` (120 с), потом `MAYBE_DISTRACTED` → по правилу 6 может стать `DISTRACTED` | `state_machine.py` |
| Кнопка подставки без сессии | Короткое нажатие стартует сессию | `manager.py` → `_on_button` |
| Протокол: как узнать состояние датчика при подключении | Добавлена команда `STATUS` (ответ `DOCK 0/1`), описана в `PROTOCOL.md` как дополнение | `device/serial_link.py`, прошивка |
| Принудительная категория в панели разработчика | Простой считается 0, процесс пишется как «(панель разработчика)», чтобы не винить реальную программу | `manager.py` |
| API | Добавлен `POST /api/session/presence` — ответ «Я здесь» | `api/server.py` |
| Таблицы БД | Сверх минимума: `farm` (размер огорода), `schema_version`; в `sessions` добавлены `maybe_s`, `paused_s`, `end_reason` | `storage/db.py` |
