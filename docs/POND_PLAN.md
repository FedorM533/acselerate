# План: «Фокус-пруд» (ферма → пруд + телефон по кабелю)

Статус на момент коммита. Отмечено, что сделано без телефона, а что ждёт проверки на реальном телефоне.

## Сделано (проверено тестами)
- [x] **Фаза 1. USB-датчик** — `sensors/usb_phone.py`: опрос (Windows `Get-PnpDevice`, macOS `system_profiler`), привязка «до/после» по VID+серийному номеру, ручной выбор из списка, ошибки опроса не роняют программу. `Dock` принимает любой способ (`device.phone_source`: auto / usb / serial / mock).
- [x] **Фаза 2. Строгий старт** — без телефона таймер не запускается; «тренировка без телефона» без роста рыбок.
- [x] **Фаза 3. Игра-пруд** — гуппи, золотая рыбка, карп кои, скалярия, аравана; ил вместо сорняков; выпуск рыбок; декор (водоросли, камни, замок). Чистая база, без миграции.
- [x] **Фаза 4. Интерфейс** — подводная сцена, пузырьки, лучи света, мутная вода при отвлечении, 25 спрайтов рыбок (`tools/make_sprites.py`), новые тексты.
- [x] **Фаза 5. Мастер привязки** — Настройки → «Телефон по кабелю».
- [x] **Фаза 6. Документы** — README, CLAUDE.md, DECISIONS.md, DEMO.md, скриншоты.

- [x] **Игровая глубина** — задания дня, ачивки, здания, коллекция с именами, плавающие рыбки; всё по правилу «не отвлекать» (см. DECISIONS.md).

## Ждёт телефона (сделать, когда он будет рядом)
1. `python scripts/usb_spike.py` — посмотреть, как телефон виден компьютеру (Android / iPhone, режимы «зарядка» и «передача файлов»).
2. Привязать телефон в Настройках и проверить: подключил кабель → сессия стартует сама; отключил → «Телефон отключён» (льготные 30 с).
3. Проверить, что режим USB телефона не меняет идентификацию (ключ — VID + серийный номер).
4. Если у устройства нет своего серийного номера, Windows подставляет номер порта (`5&9138C96&0&1`): тогда при смене USB-порта телефон надо привязать заново.

## Потом
- Своё окно приложения / `.exe` (pywebview + PyInstaller).
- Android-приложение с блокировкой других приложений по белому списку (на iPhone сторонние приложения так не умеют — там встроенное «Фокусирование»).

## Известные ограничения наград (по ревью)
- Сессия, перешедшая через полночь, засчитывается в день своего начала; задания прошлого дня за неё не выдаются.
- Если открыть старую базу (до миграции 2), награды за уже накопленную историю (часы фокуса, серия) выдадутся разом при первом простое. Старые тренировки без телефона в ней не отличить от обычных сессий.
- Демо/dev-сессии идут в задания и ачивки наравне с обычными.
- Миграции не атомарны (`executescript`), а монеты за награду сохраняются отдельно от записи о награде: при падении ровно в этот момент монеты могут потеряться (повторно не выдаются).
