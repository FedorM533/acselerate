# Carpo Pond — комплект для доработки

> **Есть два варианта.** v1 (этот файл) — плоская векторная графика, проще и легче. **v2** (папка `v2/`, см. `v2/README_v2.md`) — реалистичные карпы с изгибом тела, живая вода с движущимися бликами, тени, «след времени», касание воды и журнал пруда. Правила и прогресс у обоих одинаковые — выбери один и отдай агенту соответствующий промт.

Всё, что нужно ИИ-агенту, чтобы добавить в Carpo пруд с карпом: спецификация, конфиги с числами, тест-векторы, эталонный движок, 48 картинок и живой прототип.

## Как запустить (5 шагов)

1. **Посмотри прототип.** Открой `preview/pond-preview.html` двойным кликом (нужен только браузер). Слева — экран приложения: выбери 25/45/60 мин, нажми «Начать фокус» (в превью 1 секунда = 1 минута), попробуй «Завершить» и выбрать причину. Справа — панель разработчика: ползунками прокрути капли и дни, переключи день/вечер/ночь. Если что-то в визуале или правилах не нравится — поправь сейчас (см. «Как менять» ниже).

2. **Положи папку в проект.** Скопируй всю папку `carpo-pond-kit/` в корень репозитория Carpo (рядом с `README`/`build.gradle`/`package.json`). Закоммить её отдельным коммитом — так агенту проще, а тебе потом видно, что изменил агент.

3. **Открой агента в репозитории** (Claude Code, Cursor, Copilot Agent — любой, который видит файлы проекта и умеет запускать команды).

4. **Вставь промт.** Открой `AGENT_PROMPT.md`, скопируй всё ниже линии и отправь агенту. Картинки отдельно прикладывать не нужно — агент читает их из папки.

5. **Веди по фазам.** Агент остановится после **Фазы 0** (разведка + план) и после **Фазы 2** (данные + экран причины). На каждой остановке:
   - Фаза 0: проверь, что он правильно нашёл таймер и хранилище и не собирается трогать блокировку. Ответь «ок» или поправь план.
   - Фаза 2: запусти приложение, пройди одну сессию до конца и одну с прерыванием — должны появиться экран причины и текст «N мин сохранены». Ответь «ок».
   - В конце агент пришлёт отчёт с чек-листом. Пройди руками пункты, которые он отметил «проверить вручную».

## Что внутри

| Путь | Что это |
|---|---|
| `AGENT_PROMPT.md` | Промт для агента (по фазам, с правилами и критериями готовности) |
| `docs/GAME_DESIGN.md` | Полная спецификация: правила, экраны, анимация, слои, архитектура, модель данных |
| `config/progression.json` | Все числа: капли, бонусы, лимиты, 16 открытий с координатами, стадии |
| `config/progress_test_vectors.json` | 19 сценариев «вход → ожидаемый результат» для автотеста движка |
| `config/interrupt_reasons.json` | 6 причин прерывания |
| `config/strings_ru.json` | Все тексты интерфейса пруда |
| `config/palette.json` | Время суток, тонировка, цвета UI, параметры анимации |
| `reference/progressEngine.js` | Эталон движка; `node reference/checkVectors.mjs` проверяет его на векторах |
| `assets/svg/` | 48 векторных картинок (вид сверху) |
| `assets/png/1x,2x,3x/` | Те же картинки в PNG для мобильных; `png/full/` — фоны воды 2000×3200 и иконки 1024 |
| `assets/manifest.json` | Список ассетов: размеры, тип, пивот хвоста карпа |
| `preview/pond-preview.html` | Интерактивный прототип (эталон поведения) |
| `preview/screens/` | Скриншоты стадий: старт → месяц → полный пруд, день/вечер/ночь |
| `references/` | Твои картинки-референсы — только для настроения, **в приложение не класть** |
| `tools/` | Скрипты, которыми сделан комплект (перегенерация картинок, векторов, превью) |

### Картинки
- **Карпы:** Кохаку (стартовый), Огон (золотой), Танчо, Санке, Асаги, Платиновый — каждый цельный + `_body` + `_tail` для анимации хвоста; общая мягкая тень `koi_shadow`.
- **Вода:** `water_day`, `water_dusk`, `water_night` + слой бликов `caustics`.
- **Растения и декор:** 3 вида кувшинок, лотос розовый/белый/бутон, 3 камня + 3 варианта с мхом, тростник, папоротник, коряга, каменный фонарь + свечение, ветка сакуры, лепесток.
- **Эффекты:** круги на воде, частица света, светлячок.
- **Иконка приложения:** `app_icon` + `app_icon_foreground` / `app_icon_background` (для адаптивной иконки Android).

Все картинки нарисованы с нуля под этот проект — их можно свободно использовать в приложении.

## Как менять

- **Числа** (сколько капель за что, когда что открывается, где стоит объект) → правь `config/progression.json`, потом:
  ```
  python3 tools/make_test_vectors.py     # пересчитать ожидания тестов
  node reference/checkVectors.mjs        # убедиться, что эталон сходится
  python3 tools/build_preview.py         # обновить превью
  ```
- **Цвета картинок** → словарь `PALETTE` в начале `tools/generate_assets.py`, затем `pip install cairosvg` и `python3 tools/generate_assets.py` (пересоздаст SVG, PNG и manifest) и `python3 tools/build_preview.py`.
- **Тексты** → `config/strings_ru.json`, `config/interrupt_reasons.json`.

## Если агент буксует

- Путается в проекте → попроси: «Сначала покажи, какие файлы отвечают за таймер сессии и хранилище, ничего не меняй».
- Тесты движка не проходят → «Сравни свою реализацию с `reference/progressEngine.js` построчно; проверь целочисленный бонус и сортировку по endedAt».
- Пруд выглядит иначе, чем в превью → «Открой `preview/pond-preview.html`, функции `buildScene`, `placeImg` и `tick` — повтори их логику один в один».
- Хочет тянуть игровой движок → «Нет, рисуем средствами UI-фреймворка проекта, как в правилах».
