# Протокол подставки «Фокус-док»

Связь ESP32 ↔ ноутбук по USB-serial.

- Скорость **115200 бод**, 8N1.
- Текстовые строки в ASCII, каждая заканчивается `\n` (`\r` перед ним игнорируется).
- Неизвестные строки обе стороны молча игнорируют.

## Устройство → ПК

| Строка | Когда |
|---|---|
| `HELLO fw=0.1` | сразу после включения/перезагрузки |
| `DOCK 1` | телефон положили (антидребезг 300 мс на стороне устройства) |
| `DOCK 0` | телефон убрали (антидребезг 300 мс) |
| `BTN PAUSE` | короткое нажатие кнопки (< 1 с): пауза / продолжить, без сессии — старт |
| `BTN NOTEBOOK` | долгое нажатие (≥ 1 с): включить/выключить режим «пишу в тетради» |
| `PONG` | ответ на `PING` |

## ПК → устройство

| Строка | Что делает |
|---|---|
| `LED GREEN` / `YELLOW` / `RED` / `BLUE` / `OFF` | цвет кольца WS2812 |
| `LED BLINK_RED` | мигающий красный (телефон вынут) |
| `SOUND <n>` | проиграть mp3 номер n на DFPlayer Mini |
| `PING` | проверка связи, ответ `PONG` |
| `STATUS` | *(дополнение к ТЗ)* устройство отвечает текущим `DOCK 0/1` — ПК шлёт его при подключении, чтобы не ждать, пока телефон тронут |

### Звуки (файлы на microSD DFPlayer: `/mp3/0001.mp3` … `0004.mp3`)

| n | Звук |
|---|---|
| 1 | мягкий сигнал (телефон вынут) |
| 2 | сигнал «отвлёкся» |
| 3 | «урожай собран» |
| 4 | «сессия началась» |

## Поведение ПК

- Раз в 5 с ПК шлёт `PING`. Если от устройства ничего не приходит 12 с, связь
  считается потерянной: интерфейс пишет «Подставка не подключена», программа
  переключается на виртуальную подставку и каждые 3 с пытается подключиться снова.
- После (пере)подключения ПК шлёт `STATUS` и текущий цвет `LED …`.
- Ограничение частоты звуков — на стороне ПК (`reactions.py`), устройство
  просто проигрывает то, что пришло.

## Пример сессии

```
← HELLO fw=0.1
→ STATUS
← DOCK 0
→ LED OFF
← DOCK 1          (положили телефон)
→ SOUND 4
→ LED GREEN
→ PING
← PONG
← DOCK 0          (взяли телефон)
→ LED BLINK_RED   (через 30 с льготного времени)
→ SOUND 1
```

## Проверка вручную

```
python -m focusfarm.tools.serial_console --list
python -m focusfarm.tools.serial_console --port COM3
> LED GREEN
> SOUND 4
> PING
```
