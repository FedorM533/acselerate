# Задача: перевести интерфейс Carpo на новый фирменный стиль

Ты работаешь над проектом **Carpo** — локальный помощник для учёбы, который во время сессии блокирует отвлекающие программы и сайты на компьютере и телефоне. В пруду растут рыбки, пока человек в фокусе. Интерфейс открывается в браузере на `http://127.0.0.1:8765/`, есть расширение для браузера и Android-приложение (в разработке).

У проекта появился фирменный стиль. Нужно применить его ко всем экранам, **не меняя поведение программы**.

В корне репозитория лежит папка `carpo-design-kit/` — всё, что нужно, внутри неё.

## Что в папке `carpo-design-kit/`

| Путь | Что это | Куда идёт |
|---|---|---|
| `tokens/tokens.css` | Все цвета, шрифты, радиусы, отступы как CSS-переменные `--carpo-*`, светлая и тёмная тема | Подключить в веб-интерфейс и в страницы расширения |
| `fonts/` | Jost и Manrope в woff2 (латиница + кириллица), `fonts.css` с `@font-face`, лицензии OFL | Скопировать в статику веб-интерфейса и расширения |
| `brand/logo/carpo-mark-*.png` | Знак (два карпа) на прозрачном фоне, 64–1024 px | Шапка, пустые состояния, экран «Идёт учёба» |
| `brand/logo/carpo-mark-cream-512.png` | Знак кремовым цветом | На тёмно-зелёном фоне |
| `brand/logo/carpo-mark-mono-green-512.png` | Знак одним зелёным цветом | Где нужна одноцветная версия |
| `brand/icons/web/` | `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png` | `<head>` веб-интерфейса |
| `brand/icons/app/` | Иконка приложения 180–1024 px | Ярлык Windows, окно, README |
| `brand/icons/extension/icon{16,32,48,128}.png` | Иконки расширения | `manifest.json` расширения |
| `brand/icons/android/` | `mipmap-*` (обычная, круглая, адаптивная), `mipmap-anydpi-v26/*.xml`, `values/carpo_colors.xml` | `android/app/src/main/res/` |
| `reference/landing-*.html` | Три макета сайта в этом стиле (A — светлый, B — тёмный, C — с карточкой сессии) | Образец внешнего вида. Открыть в браузере и смотреть |
| `reference/brand-board.jpg` | Исходный брендбук | Образец |

## Прежде чем менять код

1. Прочитай `CLAUDE.md`, `docs/TECHNICAL.md`, `docs/PROGRESS.md`. Найди, где лежат шаблоны и стили веб-интерфейса, страницы расширения (в т. ч. страница блокировки сайта), экраны Android-приложения.
2. Открой `reference/landing-A-quiet-pond.html` и `reference/landing-C-product.html` — это главный образец. `landing-B-dark-water.html` — образец тёмной темы.
3. Составь список экранов и компонентов, которые будешь менять, и покажи его мне перед большими правками.

## Правила

- **Никаких запросов в интернет.** Carpo обещает работать офлайн: шрифты только из `fonts/`, никаких Google Fonts, CDN и внешних картинок.
- **Только оформление.** Не менять логику, тексты кнопок, тесты, API, формат конфигов. Если без изменения разметки не обойтись — меняй разметку, но не поведение.
- Цвета, шрифты и радиусы — **только через переменные** из `tokens.css`, без новых захардкоженных hex.
- Заголовки, таймер и надпись «Carpo» — Jost (200–400), весь остальной текст и кнопки — Manrope.
- Терракотовый `--carpo-clay` не использовать для мелкого текста на светлом фоне (не хватает контраста). Для текста — `--carpo-ink*`, для крупных цифр — `--carpo-clay-text`.
- Доступность: контраст текста ≥ 4.5:1, кликабельные элементы ≥ 44 px, видимый фокус при навигации с клавиатуры, у картинок-знаков пустой `alt` (декор) или осмысленный (логотип в шапке).
- Интерфейс должен нормально выглядеть и на узком окне (от 360 px).
- Без эмодзи, градиентов и теней кроме `--carpo-shadow-card`.

## Как должны выглядеть компоненты

- **Фон** страницы — `--carpo-bg` (кремовый). Карточки — `--carpo-surface`, радиус `--carpo-radius-lg`, без рамки или с тонкой `--carpo-border`.
- **Шапка**: иконка 36–40 px со скруглением + надпись «Carpo» (Jost 300, 24–28 px) слева, навигация справа.
- **Основная кнопка**: фон `--carpo-primary`, текст `--carpo-on-primary`, Manrope 600, форма «таблетка» (`--carpo-radius-pill`), высота ≥ 44 px. Вторичная — прозрачная с рамкой цвета `--carpo-primary`.
- **Чипы** (режимы, списки, «где защищать»): «таблетка» с тонкой рамкой; выбранный — заливка `--carpo-clay` с тёмным текстом `--carpo-ink`.
- **Карточка сессии** — как в `landing-C-product.html` (блок справа на первом экране): статус «В фокусе» в чипе, знак 96 px, таймер Jost 200 `--carpo-timer`, подпись «осталось», полоса роста рыбки (фон `--carpo-sage-light`, заполнение `--carpo-clay`), список закрытого в чипах. Это главный экран во время сессии.
- **Состояние «рост на паузе»**: чип статуса меняется на `--carpo-paused-bg` / `--carpo-paused`, полоса роста — приглушённая. Без красного и без пугающих формулировок: рыбки никогда не погибают.
- **Пруд**: круглая подложка `--carpo-sage` (как во втором блоке `landing-A`), рыбки внутри. Существующую графику рыб не трогать, только окружение.
- **Настройки**: группы в карточках, переключатели и радио — в цвете `--carpo-primary`, подписи `--carpo-ink-2`.
- **Тёмная тема**: включается атрибутом `data-theme="dark"` на `<html>`. Добавь переключатель в «Настройках» (Светлая / Тёмная / Как в системе), сохраняй выбор там же, где остальные настройки.

## Что сделать по частям

1. **Веб-интерфейс**: подключить `fonts.css` и `tokens.css`, favicon, перекрасить все экраны (старт сессии, сессия, пруд и магазин, настройки, телефон по Wi-Fi с QR, строгий режим, предупреждения мягкого режима). Если в проекте уже есть экран паузы с обратным отсчётом или итог сессии — оформить и их в этом стиле.
2. **Расширение для браузера**: иконки в `manifest.json`, страница блокировки сайта — кремовый фон, знак по центру, заголовок Jost «Идёт учёба», подпись Manrope, оставшееся время, если оно уже передаётся.
3. **Android**: иконки из `brand/icons/android/` в `res/`, цвета из `carpo_colors.xml`; экран «Идёт учёба» — фон `carpo_green`, кремовая иконка/знак по центру, заголовок «Идёт учёба», кнопка «Вернуться» в стиле основной кнопки. Шрифты Jost/Manrope — если в проекте уже есть механизм шрифтов; если нет, оставить системный шрифт и написать об этом.
4. **Windows**: иконка приложения/ярлыка из `brand/icons/app/` (собрать `.ico` из PNG, если нужно), если у программы есть ярлык или окно.
5. **README**: заменить заголовок на иконку + название; добавить в `docs/` короткий `DESIGN.md` — откуда токены, какие шрифты и лицензии, как включить тёмную тему.

## Как сдавать

- По частям: после веб-интерфейса покажи результат (скриншоты или список изменённых экранов), потом расширение, потом Android.
- Все существующие тесты проходят. Демо-режим (`run_demo.bat`) работает.
- Обнови `docs/PROGRESS.md`.
- В конце — отчёт: что изменено, что не удалось и почему, где пришлось отступить от этого описания.
